# Samples for `transnote compare`

One folder per piece. Inside it, every image/PDF is an **input variant**, and
`truth.musicxml` (or `truth.mxl`) is the correct score:

```
samples/
  my-march/
    truth.musicxml      ← hand-corrected, the "right answer"
    scan.pdf            ← Apple "Scan Documents" PDF (any number of pages)
    photo.jpg           ← plain phone photo
    photo2-1.jpg        ← a variant with several pages:
    photo2-2.jpg           <variant>-<page number>.<ext>
```

Name variants so they group well in the report: `scan…` for scans,
`photo…` for photos (trailing digits are ignored when averaging, so
`photo` and `photo2` count as one kind).

## Making the ground truth

1. Run an engine on the scan: `transnote scan samples/my-march/scan.pdf -o samples/my-march/truth.musicxml --open`
2. In MuseScore, fix every mistake against the printed page: notes, rests, ties, key, time signature.
3. *File → Export → MusicXML*, overwrite `truth.musicxml` (uncompressed `.musicxml` or `.mxl`, either is fine).

Tip: don't change the instrument while correcting. The comparison checks
**written** pitches, as printed on the page.

A folder without a truth file is still processed. You then only get timing and
the bar checks, which is handy for choosing which result to correct.

## What to collect

5–10 pieces that are typical of what you play, ideally each as both `scan.pdf`
and `photo.jpg`. Include some harder ones: ties across bar lines, triplets,
repeats/voltas, dense eighth/sixteenth passages, accidentals.

## Privacy / copyright

Printed sheet music is usually copyrighted. Keep this repository **private**
if you commit real pages here. The `synthetic-*` folders are generated by
`scripts/make_synthetic_samples.py` and are free to share.
